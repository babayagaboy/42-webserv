HTTP Methods

Pick a request. The playground builds the example for you.

GET↙

Retrieve a resource

Ask the server for a page, file, or other resource.

GET /index.html HTTP/1.1
POST↑

Send some data

Submit a body to your server and inspect the response.

POST /submit HTTP/1.1
PUT↻

Update a resource

Send a complete representation to update a resource.

PUT /resource/42 HTTP/1.1
DELETE×

Remove a resource

Request that a resource be removed by the server.

DELETE /resource/42 HTTP/1.1
HEAD◉

Headers only

Like GET, but ask for response headers without the body.
